# ВТБ · Апартамент

Статический интерактивный график ипотеки: остаток на дату, ближайший платёж, диаграмма долга и платежей по годам, выбор платежа, фильтры, пагинация, экспорт отфильтрованных строк CSV. Без зависимостей, аналитики и запросов к сторонним сервисам.

Источник: банковский график от 01.11.2026. Все 271 строка сохранены, включая заключительную нулевую строку. Денежные значения хранятся целым числом копеек. Проверены последовательность номеров, равенство платежа сумме долга и процентов, изменение остатка каждой строки и итоговый нулевой остаток. Итог: 39 986 527,40 ₽, основной долг 11 503 040,78 ₽, проценты 28 483 486,62 ₽.

Остаток на дату отражает план после строк с более ранней датой и отдельно подтверждённые погашения за саму выбранную дату. Платёж № 64 от 01.11.2026 на 2 000,00 ₽ подтверждён владельцем как погашенный: он включён в остаток на 01.11 и исключён из предстоящих платежей. Остаток после него — 10 729 985,05 ₽; ближайший платёж — 182 574,96 ₽ на 12.11.2026. Подтверждённая строка остаётся в полном графике с отметкой «Погашен». Для диапазона дат используется конечная дата. Ставка 19,70% — значение из шапки документа; исторические платежи не пересчитываются. Заёмщик, договор, банковский счёт и исходный PDF не публикуются.

Локально: `python3 -m http.server 4173 --bind 127.0.0.1` из этой папки. Открыть http://127.0.0.1:4173.

GitHub Pages: ветка `gh-pages`, каталог `/`. Сборка не требуется.

По умолчанию таблица показывает весь график на одной странице без кнопок перехода. Переключатель «Показать» позволяет выбрать «По 12 месяцев»; все платежи одного месяца остаются вместе. Фильтры периода, года и поиска работают в обоих режимах. Фильтры применяются до разбиения на страницы. Под таблицей можно ввести номер страницы и нажать «Перейти» или Enter; показан диапазон месяцев. Выгрузка CSV содержит все отфильтрованные строки, независимо от выбранной страницы.

Вход по четырёхзначному PIN: экран входа скрывает интерфейс до проверки, кнопка «Выйти» закрывает его. Вход запоминается только в текущей вкладке через `sessionStorage`; сам PIN не сохраняется. Проверяется SHA-256 отпечаток. Это удобная блокировка интерфейса, не серверная авторизация: данные и код остаются публичными на GitHub Pages, блокировку можно обойти. Для конфиденциальных данных необходима серверная проверка доступа.

Главный экран показывает календарный срок до последнего ненулевого платежа (14.12.2043) от выбранной даты. На 01.11.2026 это 17 лет, 1 месяц и 13 дней; количество месяцев не является количеством платежных строк.

Сводка октября фиксирована по PDF: плановый платёж № 54 выделен явно, остальные 15 октябрьских операций считаются досрочными. Досрочно внесено 30 196,00 ₽, из них основной долг 29 966,91 ₽ и проценты 229,09 ₽. Суммарное уменьшение основного долга за октябрь — 38 346,40 ₽.

План ноября отделяет отражённую в PDF операцию № 64 от будущего платежа № 65: 2 000,00 ₽ внесено 01.11, платёж 12.11 — 182 574,96 ₽ (основной долг 3 046,14 ₽, проценты 179 528,82 ₽). Дополнительные будущие досрочные платежи в план не заложены. Эти месячные сводки не меняются при выборе даты просмотра графика.

Внизу страницы находится аркада «Халим против ипотеки». Число препятствий берется из будущих ненулевых платежей на текущую московскую дату, без подтвержденных погашений (206 на 01.11.2026). Прыжок: кнопка, пробел, стрелка вверх или касание поля; P — пауза. Ежедневные игровые взносы по 2 000 ₽ ускоряют бег, кнопка ускорения временно удваивает скорость. Игра не изменяет данные графика и не прогнозирует реальную дату погашения. Пауза включается при уходе из вкладки или прокрутке игры за пределы экрана. Зависимостей и сетевых запросов нет.
