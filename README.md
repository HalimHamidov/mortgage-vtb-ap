# ВТБ · Апартамент

Статический интерактивный график ипотеки: остаток на дату, ближайший платёж, диаграмма долга и платежей по годам, выбор платежа, фильтры, пагинация, экспорт отфильтрованных строк CSV. Без зависимостей, аналитики и запросов к сторонним сервисам.

Источник: банковский график от 12.10.2026. Все 264 строки сохранены, включая заключительную нулевую строку. Денежные значения хранятся целым числом копеек. Проверены последовательность номеров, равенство платежа сумме долга и процентов, изменение остатка каждой строки и итоговый нулевой остаток. Итог: 40 552 275,74 ₽, основной долг 11 503 040,78 ₽, проценты 29 049 234,96 ₽.

Остаток на дату отражает план после строк с более ранней датой, а не подтверждённую оплату. Для диапазона дат используется конечная дата. Ставка 19,70% — значение из шапки документа; исторические платежи не пересчитываются. Заёмщик, договор, банковский счёт и исходный PDF не публикуются.

Локально: `python -m http.server 4173 --bind 127.0.0.1` из этой папки. Открыть http://127.0.0.1:4173.

GitHub Pages: ветка `gh-pages`, каталог `/`. Сборка не требуется.
